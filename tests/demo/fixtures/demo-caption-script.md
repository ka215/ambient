# Ambient Demo Caption Script

## 0:00 - 0:25

Ambient は、YouTube と PC ローカルの動画・音楽ファイルをブラウザ上でまとめて管理できる、無料のオープンソースメディアプレイヤーです。

## 0:25 - 1:20

YouTube の URL とローカルメディアを同じプレイリストに混在させられることが、Ambient の最大の特長です。URL を貼るだけで、自分だけのメディアリストを作れます。

## 1:20 - 1:55

追加した YouTube 動画は、そのまま再生してフルWindow表示に切り替えられます。下部メニューを最小化すれば、映像を主役にしたシンプルな再生画面になります。

## 1:55 - 2:35

メディアごとに再生開始・終了時間を指定したり、フェードイン・フェードアウトを設定したりできます。作業用 BGM や環境映像を、自分好みに細かく調整できます。

## 2:35 - 2:55

作成したプレイリストは JSON 形式でエクスポートできます。バックアップや別の PC への移行、他のユーザーとの共有にも使えます。

## 2:55 - 3:10

ブラウザがあれば、Ambient は誰でも無料で利用できます。自分だけのメディア環境を作ってみてください。
